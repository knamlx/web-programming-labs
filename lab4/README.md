# Практическая работа 4 — Знакомство с базовыми тегами HTML

**Выполнила:** Короткова Н. А., группа ИСТ-33.

## Запуск

Откройте `index.html` — меню четырёх заданий. Страницы также можно открывать отдельно:

1. `welcome.html` — текст из методички, выделение HTML и CSS через `strong`, элемент `time` с текущей датой.
2. `signs.html` — 15 дорожных знаков: три абзаца по пять изображений, подсказки jQuery UI Tooltip.
3. `404_page.html` — самостоятельно разработанный макет страницы ошибки с сообщением «Страница не существует» и ссылкой «Вернуться на главную».
4. `todo_list.html` — список дел с добавлением и удалением задач, проверкой пустого ввода, фоновым изображением, SVG-кнопками и собственной цветовой палитрой.

Стили находятся в `css/`, сценарии — в `js/`, изображения — в `img/`. Список дел хранится до перезагрузки страницы, как в базовом примере практикума. Страница 404 является учебной HTML-страницей и сама по себе не устанавливает HTTP-статус сервера.

## Материалы

Знаки взяты из [материалов практикума](https://github.com/SerjiEvg/web-development-practicum/tree/main/works/04-html-basics/assets/signs). Для подсказок jQuery 3.7.1, jQuery UI 1.14.1 и CSS-тема подключены с `code.jquery.com`, поэтому требуется доступ к интернету. Остальные ресурсы страницы загружаются локально.
