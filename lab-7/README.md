Для локального просмотра откройте `site/index.html` в браузере. Сборка и внешние ресурсы не требуются.

Страница использует SF Pro Display, если он установлен и доступен браузеру. На других устройствах загружается системный шрифт. Файлы SF Pro в проект не входят.

В режиме Desktop карточки расположены в три колонки, в режиме Mobile — в одну. Переключатели находятся в шапке. При пересечении порога ширины 768 CSS-пикселей страница автоматически выбирает представление по ширине окна. Выбранный тариф сохраняется при любой смене компоновки. Вручную включённый Desktop на узком экране можно прокручивать внутри области тарифов.
