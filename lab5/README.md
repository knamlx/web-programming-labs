## Открытие страницы

Скачайте папку целиком и откройте `index.html` в браузере. Установка зависимостей не требуется. Стили находятся в `css/style.css`, изображения — в `images/`.

## Выполненная работа

Использованы `header`, `nav`, один `main`, `section`, `article`, `aside` и `footer`. Есть сведения о специалисте, навыки, опыт обучения, портфолио и контакты. Для изображений с подписями применены `figure` и `figcaption`, для контактов — `address`, для дат — `time`. Меню ведёт к разделам страницы; изображения работ можно открыть в полном размере.

Страница свёрстана отдельными HTML-элементами с внешним CSS, Grid и Flexbox. Основная композиция содержит шапку, основную колонку, боковую область справа и подвал. Идея дизайна взята из примера, найденного на просторах интернета. Пример использован для вдохновения при выборе цветов, типографики и оформления карточек. Страница собрана из отдельных элементов HTML и CSS.

Согласно специальному ограничению варианта 10 реализация фиксированная, без адаптивности, эффектов и JavaScript. Это ограничение противоречит общим требованиям задания 2 по переходам и адаптивности; в данной работе соблюдено условие варианта. Проверено в Chrome: при 1280 и 1440 px горизонтального переполнения нет, при 390 px фиксированный макет прокручивается по горизонтали.

Основной шрифт — установленный локально `SF Pro Display`. Если его нет на компьютере, браузер использует системный запасной шрифт. Файлы шрифта в репозиторий не включены.
