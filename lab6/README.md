# Практическая работа 6 — Введение в CSS3

Короткова Н. А., ИСТ-33. Вариант 10 — Стриминговый сервис CineFlow.

## Запуск

Откройте `index.html` в браузере. Стили и изображения находятся локально.

## Структура проекта

- `index.html` — страница работы.
- `css/style.css` — стили.
- `images/` — изображения и иконки.
- `Отчет_практическая_работа_6.docx` — отчёт.

Реализованы карточки, прогресс просмотра, CSS-переходы и анимации, адаптивность и фильтр избранного. Названия фильмов учебные. JavaScript не используется.
