# Практическая работа 8. Создание веб-интерфейса с использованием Bootstrap

Короткова Н. А., ИСТ-33. Вариант 10 — «Учебная платформа».

- [Интерфейс](index.html)
- [Отчёт Word](Отчет_практическая_работа_8.docx)

Откройте `index.html` в браузере. Bootstrap 5.3.3 подключён локально, поэтому для самого интерфейса не нужны сборка и интернет. Собственное оформление находится в `css/style.css`. Интерактивность меню, вкладок и модулей реализована штатными компонентами Bootstrap.

В кабинете показан урок «Структура HTML-документа». Обложка создана для демонстрации интерфейса. Прогресс, курс и преподаватель представлены демонстрационными данными. Пункт «Поиск по курсу» открывает быстрый переход к разделам.

Концепт и требования — практикум, часть 2 (v2), с. 10–12 и 24–25. [Документация Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/introduction/).
